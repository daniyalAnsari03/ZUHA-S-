# STEP 9 — AUTHENTICATION FOUNDATION

Establish the authentication architecture for:

## Customers

Support:

* email/password
* Google OAuth

## Admin

Prepare secure role-based authorization.

Authentication and authorization must remain separate.

A logged-in user must not automatically become an admin.

Use secure session handling appropriate for Next.js App Router and Supabase.

Protect server-side operations.

Do not expose sensitive credentials.

If OAuth credentials are not available, build the architecture without fake credentials.

# STEP 11 — RLS FOUNDATION

RLS is a mandatory security boundary.

Establish the foundation for:

* customer ownership
* admin access
* protected resources

When update_product is called to change ONLY the description (or any single
field), the model sometimes also includes a guessed "slug" value (often
containing a space, which fails validation) even though the user never asked
to change it. Fix: make it explicit in productAgent's instructions — only
include fields the user is actually changing; never guess or include slug
unless the user explicitly asked to rename/change the product's URL slug.
Also confirm the tool schema itself doesn't require slug on every update call
(it should be fully optional, omittable).
